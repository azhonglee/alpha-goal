# 控制律

## 界面展示

只有用户要求、持久化受阻或高风险复核时，才打印原始控制律。

```markdown
执行检查

| 字段 | 内容 |
| --- | --- |
| 问题 | 目标误差 |
| 本轮动作 | 控制变量、控制动作或探测 |
| 保持不变 | 保持不变的变量与饱和条件 / 约束边界 |
| 验收证据 | 传感器与阈值 / 容差 |
| 主要风险 | 信号噪声、阻尼 / 防振荡、饱和条件 / 约束边界，或最强实质风险 |
| 失败处理 | 失败处理、停止或重新界定触发条件 |
```

## 内部结构

内部产物格式，不是默认 TUI 展示格式。schema sidecar 是机器可读的摘要与索引；不要把 schema sidecar 当成完整控制律。

```text
控制律:
- 目标误差:
- 控制变量:
- 控制动作或探测:
- 保持不变的变量:
- 预期效果:
- 传感器:
- 阈值 / 容差:
- 反馈延迟:
- 信号噪声:
- 置信度:
- 阻尼 / 防振荡:
- 饱和条件 / 约束边界:
- 失败处理:
```

## 内部产物示例

持久化产物，不是默认 TUI 展示；不要把它作为默认执行前展示。

```text
控制律:
- 目标误差:
- 控制变量:
- 传感器:
```
