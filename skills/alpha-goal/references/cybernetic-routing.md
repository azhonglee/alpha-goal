# Cybernetic Routing

Route by dominant uncertainty: reference ambiguity -> goal-contract; plant/sensor/actuator uncertainty -> system-model; stakeholder/value conflict -> decision-synthesis; approved bounded action -> control-loop; final claim -> evidence-verify; missing authority/tool/data -> blocker. Stability failures are overbroad claims, hidden actuator boundaries, missing sensors, unregistered disturbances, and uncontrolled external side effects.
