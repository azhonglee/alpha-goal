# Routing

Choose the smallest controller that reduces uncertainty:

- unclear target/scope/evidence/authority -> frame in `contract-and-model.md`
- unclear plant/sensors/actuators/coupling/ownership -> model in `contract-and-model.md`
- stakeholder/value/indicator conflict, high coupling, high consequence -> synthesize in `synthesis.md`
- explicit bounded action authority -> `control-loop`
- final/ready/safe/complete/repair claim -> `evidence-verify`
- missing user-owned decision, credential, permission, environment, or external side effect authority -> ask/block

Never let `alpha-goal` create mutation authority; it only records authority from user/repo instructions.
