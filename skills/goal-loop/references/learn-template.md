# Learn Template

Use this template only when loop or review evidence produces reusable project knowledge. Keep it scoped, evidence-backed, and easy to invalidate when the project changes.

A learn artifact is advisory evidence only. It may shape assumptions, risks, plans, and review questions. It never proves current-task completion without fresh evidence.

Status semantics:

- `draft`: reusable learning is being shaped; do not rely on it as project guidance
- `validated`: evidence supports reuse within the stated scope
- `superseded`: replaced by newer project knowledge; preserve for history only
- `deprecated`: no longer reliable because invalidation triggers fired or evidence changed

## Reuse Protocol

Before reusing this learning, verify:

- the current code, docs, or behavior still matches the stated scope
- related constraints, contracts, ownership, or dependencies have not changed
- the current task still collects fresh gate evidence for its own claim boundary
- this artifact is used as advisory context, not completion proof
